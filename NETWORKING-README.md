## 🛠 Техническая архитектура

### **Frontend**
- **React 18** с TypeScript
- **Chakra UI** для компонентов
- **Framer Motion** для анимаций
- **React Router** для навигации
- **React Hooks** для управления состоянием

### **Backend**
- **Firebase Firestore** для базы данных
- **Firebase Authentication** для авторизации
- **Firebase Security Rules** для безопасности

### **Ключевые компоненты**
```
src/
├── components/networking/
│   ├── EnhancedProjectCard.tsx      # Карточка проекта
│   ├── EnhancedSearchFilters.tsx    # Фильтры поиска
│   ├── CreateProfileForm.tsx        # Форма создания профиля
│   ├── CreateProjectForm.tsx        # Форма создания проекта
│   ├── RecommendationsInsights.tsx  # Рекомендации и инсайты
│   └── NetworkingStats.tsx          # Статистика
├── hooks/
│   ├── useProjects.ts               # Хук для работы с проектами
│   └── useNetworkingProfile.ts      # Хук для работы с профилями

│   └── recommendationAlgorithm.ts   # Алгоритм рекомендаций

    └── projectService.ts            # Сервис для проектов
```

## 🚀 Как запустить

### 1. **Установка зависимостей**
```bash
npm install
```

### 2. **Настройка Firebase**
- Убедитесь, что Firebase проект настроен
- Проверьте конфигурацию в `src/firebase.ts`
- Разверните правила Firestore: `firebase deploy --only firestore:rules`

### 3. **Запуск приложения**
```bash
npm run dev
```

### 4. **Добавление тестовых данных (опционально)**
```bash
node scripts/seed-networking-data.cjs
```

## 🎯 Алгоритм рекомендаций

Система учитывает следующие факторы:
- **Навыки** (25% веса)
- **Интересы** (20% веса)
- **Локация** (15% веса)
- **Опыт** (15% веса)
- **Категории** (10% веса)
- **Технологии** (10% веса)
- **Доступность** (5% веса)
